# 🤖 Machine Learning Specialization Projects

Welcome to my **Machine Learning project repository**!  
This repository serves as a personal collection of all the practice notebooks (labs) and programming assignments I've completed while taking the **Machine Learning Specialization** by **Andrew Ng** (DeepLearning.AI & Stanford) on Coursera.

This repository is a reflection of my learning journey — from **fundamental concepts** to **more advanced algorithms**.

---

## 📚 Repository Structure

This project is organized based on the **three main courses** in the specialization.  
Each folder contains the notebooks relevant to the topics covered in each course.

---

### 📘 **Course 1: Supervised Machine Learning — Regression and Classification**

This folder covers the fundamentals of **supervised learning** — building models that can make predictions based on labeled data.

**Key Topics Covered**:
- 📈 **Linear Regression**: Predicting continuous values (e.g., house prices).
- ⚙️ **Cost Function & Gradient Descent**: Optimization algorithms to find the best parameters.
- 📨 **Logistic Regression for Classification**: Predicting categories (e.g., spam or not spam).
- 🎯 **Overfitting & Regularization**: Techniques to create models that generalize well to new data.
- 🛠 **Implementation with Scikit-learn**: Using the popular library to build models quickly.

---

### 📗 **Course 2: Advanced Learning Algorithms**

The second course dives deeper into **complex algorithms**, focusing on **Neural Networks** and **Decision Trees**.

**Key Topics Covered**:
- 🧠 **Neural Networks**: Building and training models inspired by the human brain.
- 🔧 **TensorFlow**: Practical implementation of neural networks using Google’s popular framework.
- 🔄 **Backpropagation**: Understanding the math behind the neural network training process.
- 📊 **Model Evaluation & Selection**: Strategies for choosing the best model (Bias vs. Variance).
- 🌳 **Decision Trees & Ensemble Methods**: Intuitive rule-based algorithms for classification and regression.

---

### 📙 **Course 3: Unsupervised Learning, Recommenders, Reinforcement Learning**

This course explores **unlabeled data**, **recommender systems**, and **reinforcement learning**.

**Key Topics Covered**:
- 📌 **Clustering with K-Means**: Automatically grouping similar data points.
- 🚨 **Anomaly Detection**: Finding unusual or suspicious data points.
- 🎯 **Recommender Systems**:
  - 🤝 **Collaborative Filtering**: Recommending items based on similar users.
  - 📄 **Content-Based Filtering**: Recommending items based on item features.
- 🕹 **Reinforcement Learning**:
  - 🔁 **Markov Decision Processes (MDPs)**
  - 🧮 **Q-Learning**: Training an agent to make optimal decisions.
